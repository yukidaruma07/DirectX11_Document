# はじめに
* DirectX11を勉強するためには、まずはウインドウの生成の仕方を学ぶ必要があります。

# そもそもウインドウって何？
* ソフトの1個1個の四角い枠のことです。青く囲ったものはすべて同じソフトですが、それぞれ違うウインドウです。
* 厳密には、見えないウインドウというのも存在します。青く囲っていないデスクトップ背景は、dwm.exe と言うウインドウです。

* Windows上では、ウインドウは、ハンドルという番号で区別します。
