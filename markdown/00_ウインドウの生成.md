# ②　ウインドウを作成するには？
* まず、Windowsのプログラムを作成するには、メイン関数をWinMainにすることで、作成できます。
* そして、ウインドウクラスとウインドウプロシージャーというものが必要になります。

# ①ウインドウクラス
## 説明
* cbSize - 構造体のサイズ。Windowsの構造体ではだいたい必要です。sizeofで取得すれば問題ないです。
* hInstance - インスタンス。WinMainの引数から取ってくれば問題ないです。
* lpszClassName - ウインドウクラス名。
* lpfnWndProc - ウインドウのプロシージャ（※後ほど説明）。
* hIcon - ウインドウのアイコン。デフォルトのアイコンを指定します。
* hIconSm - ウインドウの小さいアイコン。デフォルトのアイコンを指定します。
* hCursor - ウインドウのカーソル。デフォルトのカーソルを指定します。
* hbrBackground - ウインドウの背景。白の背景を指定します。
* RegisterClassEx(&wndClass); - ウインドウクラスをWindows側に登録する関数です。必ず必要です。

## コードの例
```cpp
	WNDCLASSEX wndClass = {};
	wndClass.cbSize = sizeof(WNDCLASSEX); 
	wndClass.hInstance = hInstance;
	wndClass.lpszClassName = "GameWindow"; 
	wndClass.lpfnWndProc = WndProc; 
	wndClass.hIcon = LoadIcon(nullptr, IDI_APPLICATION); 
	wndClass.hIconSm = LoadIcon(nullptr, IDI_WINLOGO); 
	wndClass.hCursor = LoadCursor(nullptr, IDC_ARROW);
	wndClass.hbrBackground = (HBRUSH)GetStockObject(WHITE_BRUSH); 
	RegisterClassEx(&wndClass);
```

# ②ウインドウを作成する
## 説明

## コードの例
```cpp
	//CreateWindowの参考：https://learn.microsoft.com/ja-jp/windows/win32/api/winuser/nf-winuser-createwindoww
	GameEngine::hwnd = CreateWindow(
		WINDOW_CLASS_NAME, //クラスの名前（※WNDCLASSEXと同じクラス名を指定する）
		title, //ウインドウの名前
		WS_OVERLAPPEDWINDOW, //ウインドウスタイル（参考：https://learn.microsoft.com/ja-jp/windows/win32/winmsg/window-styles）
		CW_USEDEFAULT, CW_USEDEFAULT, //ウインドウのX座標＆Y座標
		width, height, //ウインドウの幅＆高さ
		NULL, //親ウインドウ（※親ウインドウがいない場合はNULLで問題ない）
		NULL, //メニューのハンドル（※メニューがない場合はNULLで問題ない）
		hInstance, //インスタンス
		NULL //パラメータ
	);

	ShowWindow(GameEngine::GetWindowHandle(), nCmdShow);
	UpdateWindow(GameEngine::GetWindowHandle());
```


# ③ウインドウプロシージャー
## 説明
* 「ウインドウを作成した」「ウインドウが破棄された」「ウインドウが押された」などの、何かした場合にWindowsから情報から送られてきます。それを処理するのがウインドウプロシージャーです。

## コードの例
```cpp
LRESULT CALLBACK WndProc(HWND hwnd, UINT message, WPARAM wParam, LPARAM lParam) {
	switch (message) {
	case WM_CREATE: {
		break;
	}
	case WM_COMMAND: {
		break;
	}
	case WM_DESTROY: {
		PostQuitMessage(0);
		break;
	}
	}
	return DefWindowProc(hwnd, message, wParam, lParam);
}
```
